# 主站公开资料页面

`/downloads` 展示 `https://dl.sdutvinci.cn` 的 AList 目录 `/vdl`。页面可以逐层浏览子文件夹，
显示文件名、大小、修改日期，并使用 AList 的 `/d/vdl/...` 直链下载。`/links` 中的“资料下载”
指向这个主站页面。文件列表由主站服务端调用 AList 的 `/api/fs/list`，不需要将目录转换为 S3，
也不需要每次上传文件后提交网站代码。

## AList 访客权限设置

当前 `dl` 的匿名目录请求返回 `Guest user is disabled`。要公开 `/vdl`，先在 AList 管理页面：

1. 确认 `/vdl` 及需要展示的子目录只含可公开下载的文件。
2. 在“角色”中为访客准备仅覆盖 `/vdl` 及其子目录的只读权限作用域；不要授予上传、删除、移动或管理权限。
3. 在“用户”中编辑 `guest`，分配上述受限角色，开启“检查路径限制”，再取消“停用”。
   “基本路径”不是权限边界，不能代替角色权限作用域；先保持现有基本路径不变。
4. 用无痕窗口核对访客能读取 `/vdl`、子文件夹和具体文件；同时确认访客无法读取其他目录。

不用在 1Panel 给整个 `dl` 域名添加 `/d/vdl` 前缀：目录列表 API 仍需走 `/api/fs/list`，而文件
下载链接已经带有 `/d/vdl`。若反向代理另有路径规则，应分别验证列表接口和一个实际文件直链。

主站的列表接口按目录和页码请求 AList，每页最多 200 项，正常响应可缓存约一分钟。`/vdl`
新增或删除文件后，再打开或更新主站资料页即可看到最新列表；具体延迟还取决于 AList 后端存储缓存。
