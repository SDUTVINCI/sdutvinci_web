# 主站下载页登录与原下载站直链

主站 `/downloads` 页面及 `/api/downloads` 目录接口要求有效站点会话，
学员、正式成员和管理员均可使用。未登录时进入登录页，登录后回到原目录。
目录响应使用 `private, no-store` 和 `Vary: Cookie`，避免共享缓存。

`/links` 保留主站“资料下载”入口，只隐藏 `https://dl.sdutvinci.cn/` 下载站卡片。
直接访问原下载站以及使用原文件链接，保持原来的访问方式。

## 目录与文件

主站服务继续按原方式匿名请求 `https://dl.sdutvinci.cn/api/fs/list`，
只读取 `/vdl` 及其子目录，不发送账号、会话或服务凭据。
保留目录路径校验、分页、请求超时与错误提示。

文件链接继续使用 `https://dl.sdutvinci.cn/d/vdl/...`，对各段路径进行编码。
点击文件由浏览器直接访问原下载站，文件传输由原下载站处理。
主站不提供文件代理，也不添加下载令牌或文件来源允许列表配置。

## 部署与验证

本功能无需新增下载环境变量，不需要修改 AList、反向代理或对象存储权限，
也不需要关闭原下载站的匿名访问或使旧直链失效。
主站登录要求仅控制主站下载页面和目录接口，不改变原下载站权限。

验收时确认：

- 未登录访问主站下载页跳转登录，目录接口返回 401。
- 已登录学员、正式成员和管理员可以浏览主站资料目录。
- 文件地址仍为原下载站的编码直链。
- More 中不展示原下载站卡片，原下载站可以按原方式直接访问。
