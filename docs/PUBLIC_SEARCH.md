# 公共内容加载与全站搜索

顶部放大镜进入 `/search`。当前搜索范围为已发布新闻和 Wiki 的标题、路径及正文；成员档案和下载目录暂不参与搜索。

- 搜索词保存在 `q` 参数，`collection=news|wiki` 可限制类型；链接可复制分享，浏览器前进和后退会恢复查询。
- 最多 200 个字符，最多显示 100 条结果。精确标题、标题包含关键词、正文或路径命中依次排序。
- 摘要提取正文命中附近的文本。高亮以文本节点与 `<mark>` 渲染，不使用 `v-html`。
- 沿用既有文章访问权限：匿名搜索仅返回公开文章，登录后可搜索成员文章。接口和页面响应禁止 HTTP 缓存，页面数据按登录身份区分缓存；路由中间件在渲染前确认会话。
- 搜索页动态渲染并设置 `noindex, follow`，避免预渲染空查询或索引大量关键词页面。

首页成员统计、新闻、Wiki、成员列表和组织架构使用 `PublicContentState` 区分加载、失败及空内容；失败可重试，读取失败的统计不显示为零。下载页原有加载提示、错误提示和刷新入口继续使用。

验证：`npm run typecheck`、`npm run build`。`tests/public-search.test.ts` 验证摘要、高亮及状态组件；使用隔离 `TEST_DATABASE_URL` 运行 `tests/v2-public-content-shadow.integration.test.ts` 验证实际数据库搜索、筛选、排序、特殊字符及受限内容访问。
