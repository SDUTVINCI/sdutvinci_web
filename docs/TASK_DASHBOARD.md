# Vinci 飞书任务看板

飞书表格、应用、权限、自动化和服务器接入的实际操作记录见
[飞书接入操作记录](FEISHU_DASHBOARD_SETUP.md)。新建或调整这些配置后应同步更新该记录，勿记录真实密钥。

入口：`/dashboard`；大屏：`/dashboard?screen=1`。主站导航提供“看板”入口。

本模块参考 `tungchiahui/ysu_web` 的任务看板（`b1057a47f924510bbfc2ff24a750c9e21b2c6f2b`），
适配本站 Nuxt/Nitro 服务与 Vinci 品牌。网站成员档案仅用于头像及个人页链接。
任务仍由飞书保存和编辑，网站仅展示，不新建任务数据库，不写回表格。
这一版包含任务卡片、截止倒计时、周次/组别/关键词筛选、个人积分榜、完成趋势、详情抽屉、
桌面分页、大屏轮播及浏览器全屏。新增 GitHub 研发动态与两处 ROBOCON 倒计时，详见下文。

## 1. 飞书表格

当前任务表字段如下；身份与部门在成员表统一维护，通过查找引用同步到任务表：

| 看板用途 | 默认列名 | 类型/约定 |
| --- | --- | --- |
| 标题 | 任务名称 | 文本，兼容旧“任务详情” |
| 周次 | 周次 | 单选第1—20周，手动选择，仅显示周次 |
| 要求 | 任务要求 | 多行文本，保留换行 |
| 验收 | 验收标准 | 多行文本，保留换行 |
| 组别 | 部门 | 从成员表“组别”查找引用；每个标签独立参与筛选 |
| 身份 | 啥登 | 从成员表“啥登”查找引用；老登/小登 |
| 执行人 | 负责人 | 人员，支持多人 |
| 发布与审核人 | 发布与审核人 | 人员 |
| 截止时间 | 最晚截止日期 | 日期时间 |
| 分值 | 分值 | 数字或数字字符串（含数字单选），零分合法 |
| 完成状态 | 完成情况 | 未开始 / 进行中 / 待验收 / 已完成；兼容旧未完成为未开始 |
| 审核通过时间 | 审核通过时间 | 真实审核通过日期时间；兼容旧完成时间 |
| 成果链接 | Github链接等 | HTTPS 链接，可多条 |
| 附件 | 成果附件 | 名称及已有可用 HTTPS 查看地址；无可用地址提示到飞书查看 |
| 备注 | 备注 | 可选文本 |

成员表只保留“飞书账号（人员）、组别（多选）、啥登（单选）”三列。
任务表按负责人账号匹配成员表，避免重复手工维护部门和身份。

也兼容“所属组别/组别”“负责人.部门”“执行人”“截止时间”“完成状态”等列名。
`FEISHU_FIELD_MAP` 覆盖首选列名；该列不存在或为空时回退到默认别名，
已有旧字段映射无需为本次改名重新配置服务器。新接入留空即可，定制映射例如：

```json
{"title":"任务详情","group":"负责人.部门","assignees":"负责人","deadline":"最晚截止日期","status":"完成情况"}
```

卡片展示周次、部门、阶段、标题、负责人、分值及截止倒计时。
详情展示任务要求、验收标准、成果链接、附件、发布与审核人、审核通过时间和备注。
周次和组别同时筛选任务、积分榜及完成趋势；关键词筛选任务和完成趋势。
“未完成”汇总三个未完成阶段，“已逾期”为独立筛选与标记，不替代阶段。
趋势按审核通过时间统计，缺少、未来或无效时间不纳入趋势及按时率；不以创建或修改时间代替。
附件不暴露 file_token、受保护的下载 API 或凭证，不新增匿名下载代理。

状态为空时标记“状态未填写”，按未完成展示且不计分。未知非空状态隔离并提示；所有任务状态均异常时返回诊断错误。
仅已完成任务计分；多人任务每人记全分，同名不同飞书人员 ID 不合并，同分并列。
完成撤回、改分、转交负责人或删除任务，随下一次成功同步重算。
未设分/分值异常不计分并给出提示。缺少有效审核通过时间的任务不纳入完成趋势和按时率。

成员姓名唯一匹配本站现有成员档案时，展示本站头像并链接至稳定 `memberKey` 的个人页；
重名或未匹配时使用 Vinci 队徽，不猜测链接。成员资料读取失败不阻塞飞书任务。

个人积分榜提供「总榜 / 老登榜 / 小登榜」，身份来自任务表中成员表的“啥登”查找引用，
不再读取网站 grade 或按赛季推断。赛季配置仅用于展示，换季仍须维护标签及赛事日期。
现有记录只读权限可直接读取这些字段，无需新增服务器变量、SSH 操作或应用权限。

查找引用返回一条任务的标签集合，不能保证多人任务的人员与标签逐一对应。
仅用“单个负责人 + 单个有效身份标签”的记录按稳定飞书账号确认身份；多人任务可沿用该账号在其他单人任务中的身份。
只有多人任务、无稳定账号、标签缺失/未知或冲突时仅列总榜，并显示人数；不按姓名猜测。
若以后需要让仅出现在多人任务中的成员也自动分榜，须扩展为直接读取成员表账号映射。
各分榜独立重排、同分并列，切换不改变总榜、积分或任务列表。成员资料读取失败不阻塞分榜。

## 2. 服务端配置

所有配置只放服务器 `.env`，不放 Nuxt public runtime config、不提交真实值。

```dotenv
DASHBOARD_ENABLED=true
FEISHU_APP_ID=
FEISHU_APP_SECRET=
FEISHU_BITABLE_APP_TOKEN=
FEISHU_BITABLE_TABLE_ID=
FEISHU_BITABLE_VIEW_ID=
FEISHU_FIELD_MAP=
```

- 为 SDUT 表格配置自己的飞书应用和表格标识，不复用 YSU 的凭证、表格 token 或任务数据。
- 飞书应用需发布并获得目标多维表格的记录只读权限（`base:record:retrieve`），以及表格相应访问授权。
  若需调试字段，可另开字段只读权限（`base:field:read`）；本站接口只读取记录，不修改表格。
- 页面与接口统一使用现有网站登录会话；管理员、成员、学员等有效登录账号均可查看，无需额外口令。
- `FEISHU_BITABLE_VIEW_ID`：可选；留空读取全表，配置后按该视图筛选范围读取，避免误选单组视图。
- `FEISHU_FIELD_MAP`：可选；列名相同时留空即可。
- `DASHBOARD_PUBLIC`、`DASHBOARD_ACCESS_CODE` 已移除；旧环境变量、Bearer 口令和请求参数均不能绕过登录。

`compose.yaml` 已将这些变量传给 app-blue / app-green 的运行环境。按本站正常部署流程更新后，
配置变更需重建对应应用容器才能生效；不需要数据库迁移，也不需要为此配置 EO 函数。
应用运行网络需能通过 HTTPS 访问 `open.feishu.cn`。

## 3. 访问、缓存和故障

- `/api/dashboard` 为只读 GET；未登录或会话失效 401、已登录但未配置 503、成功 200、上游错误 502，写请求不允许。
- `/dashboard`（含 `?screen=1`）使用 `site-auth` 路由中间件；未登录跳转 `/cms/login`，保留完整回跳地址。
- API 每次先通过 `requireSiteRequestAuth` 校验网站会话，包含缓存命中；过期、撤销或停用账号不能读取任务。
- 页面自动使用同源登录 Cookie；退出登录或接口返回 401 时清空任务和详情并跳转登录页。没有独立口令输入或公开模式。
- 浏览器只保存显示偏好（组别、状态、大屏和轮播），不保存任务正文或访问凭证。网站会话继续使用现有 HttpOnly Cookie。
- API 与页面使用 `private, no-store`，并设置 noindex；任务不进入 Sitemap、新闻/Wiki 内容导出或公开搜索。
- 服务实例内任务缓存 30 秒，合并并发请求，缓存命中也需验证会话。配置改变时隔离缓存。
- 飞书认证令牌复用有效期，失效时重取一次；上游超时/错误只返回固定诊断，不返回密钥或原始响应。
- 读取失败时最多回退 15 分钟内缓存，明确标记同步中断和原更新时间；无可用缓存则报错。
  浏览器已显示的结果可继续保留，但会明确提示更新中断，不表示最新状态。
- 每次最多完整读取 2000 条记录。超限或分页异常明确报错，不把部分列表当作成功。
- 对外入口可在现有网关增加访问频率限制。不要把带有任务结果的接口响应放入公开 CDN 缓存。

## 5. GitHub 研发动态

使用 GitHub，不请求 GitCode。默认组织是 `SDUTVINCI`，仅通过官方 `https://api.github.com` 读取公开仓库。

```dotenv
DASHBOARD_GITHUB_ORG=SDUTVINCI
DASHBOARD_GITHUB_REPOS=
DASHBOARD_GITHUB_EXCLUDE_REPOS=
DASHBOARD_GITHUB_TOKEN=
DASHBOARD_GITHUB_PEOPLE=
```

- 组织模式读取全部可见公开仓库，组织配置优先于手动列表；目录每页100条，完整分页。
- 组织留空时可用 `DASHBOARD_GITHUB_REPOS=owner/repo,owner/another`，最多5个手动仓库；先验证公开性再读取统计。
- `DASHBOARD_GITHUB_EXCLUDE_REPOS` 是逗号分隔完整仓库名，可排除内容仓库或重复镜像，避免把镜像中相同的提交再次汇总。
- 默认纳入组织全部公开仓库，包括网站、内容仓库和 Fork。页面同步详情可查看实际范围及 Fork 标记。
- 可选只读 `DASHBOARD_GITHUB_TOKEN` 用于提高 API 额度；不进入浏览器。无令牌也可读取公开仓库，但受匿名请求额度限制。
- 贡献榜累加 GitHub contributors API 返回的默认分支提交贡献，完整读取作者分页，按 GitHub login 合并前8名。
  这是纳入仓库的累计提交统计，不代表本周工作量，也不对镜像提交做跨仓库去重。
- 最近动态基于每仓库最近20条 GitHub events，合并显示最近20条；仅取公开动作类型、账号、时间及仓库/事项链接，不转发提交正文、评论或邮箱。
- 成员资料 `links.github` 的个人主页账号唯一匹配后，使用本站姓名、头像和稳定 `memberKey` 链接；重名/重复账号不猜测。
- 高级映射格式为 JSON 数组，例如 `[{"name":"成员姓名","accounts":["login:github-login"]}]`。
- 贡献与动态分开缓存：无令牌30分钟、有令牌10分钟；失败后至少60秒再尝试，旧值至多保留一天。
- 每轮最多4个并发请求、8秒预算；仓库较多时跨轮继续同步，显示部分结果与真实更新时间。
  GitHub 403/429、超时或某仓库失败不会阻塞飞书任务，页面可展开逐仓库同步状态。
- 整个 API（含研发区）统一要求有效网站登录会话，并设置 `private, no-store` 和 `Vary: Cookie`。

2026-10-29 使用本机服务代码实际匿名读取 GitHub 成功：目录5个公开仓库，5/5贡献与动态同步，无不可用项；
未配置或读取 GitHub 写令牌，没有修改任何组织/仓库内容。真实飞书仍待独立配置和联调。
